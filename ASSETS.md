## What is NOT included (and how to add it)
**1. Stock photography.** The brief asked for high-quality licensed photography. This environment could not download stock photos, so none are bundled and none are claimed. Backdrops are layered vector scenes instead. The recipient's own uploaded photos are the real photography in every scene.

To add real photographic backdrops later (e.g. a forest photo for `template-17`):
1. Put a compressed JPEG/WebP (about 1920x1080, under 300 KB) in `res/backdrops/`.
2. Add it to `res/backdrops/manifest.json`, e.g. `{ "template-17": "forest.jpg" }`.
3. The engine fades it in above the vector art. If the file is missing or fails to load, the vector art stays. Nothing else changes.
4. Record the photographer, source URL and licence in the table below. Use only images whose licence allows redistribution (CC0, Unsplash/Pexels licence, or your own).

| Template | File | Photographer | Source URL | Licence |
|---|---|---|---|---|
| (none added yet) | | | | |

**2. Audio files.** Not bundled. To offer your own licensed music:
1. Put the file in `res/audio/` (MP3/OGG/M4A, ideally under 2 MB, loopable).
2. Create `res/audio/manifest.json`: `[{ "file": "my-song.mp3", "title": "My song" }]`.
3. It then appears in the wizard's Music list as "(your file)" and is stored as `file:my-song.mp3`. File names may only contain letters, digits, `_`, `.` and `-`.
4. Playback still only starts after the visitor taps, and falls back silently if the file cannot play.

**3. Characters / IP.** The playful templates (3D Cartoon, Doodle, Paper Cut, Clay, Comic) use only original shapes. No copyrighted characters are used.
